Bhai agar tu GitHub CLI (gh) aur Git ko properly samajh gaya, toh company me branching, PR, code review sab easy lagne lagega.

Main tujhe real developer workflow bata raha hu jo companies me use hota hai.

Scenario

Maan le tu ek project bana raha hai:

Todo App

Main branch me stable code rahega.

Tu ek naya feature add karega:

👉 Login Page

Iske liye alag branch banayega.

Step 1: GitHub pe Repo Create Kar

GitHub pe ja:

New Repository

Name:

todo-app

Create repo.

Step 2: Local Folder Bana
mkdir todo-app
cd todo-app

Git initialize:

git init
Step 3: Simple Code Create Kar

app.js

console.log("Todo App Started");
Step 4: GitHub Repo Connect Kar

GitHub CLI login:

gh auth login

Repository connect:

git remote add origin https://github.com/USERNAME/todo-app.git

Check:

git remote -v
Step 5: First Commit

Files add:

git add .

Commit:

git commit -m "Initial project setup"

Rename branch:

git branch -M main

Push:

git push -u origin main

Ab GitHub pe code dikh jayega.

Step 6: Branch Kyu Use Karte Hai?

Soch:

Main branch:

console.log("Todo App Started");

Ab tu login feature bana raha hai.

Agar direct main me kaam karega aur code toot gaya toh?

Production kharab.

Isliye:

main
|
|---- login-feature

Alag branch me kaam.

Main safe rahega.

Step 7: Branch Create Kar

GitHub CLI nahi, Git se:

git checkout -b login-feature

Check:

git branch

Output:

* login-feature
  main
Step 8: Code Change Kar

app.js

console.log("Todo App Started");

function login() {
    console.log("User Logged In");
}

login();
Step 9: Commit Changes
git add .
git commit -m "Added login functionality"
Step 10: Push Branch
git push -u origin login-feature

Ab GitHub pe branch aa gayi.

Step 11: Pull Request Create Using GitHub CLI
gh pr create

Questions aayenge.

Example:

Title:
Add login functionality

Body:
Added login function in app.js

PR create ho jayega.

Step 12: PR Check Kar

Browser me:

gh pr view --web

Ya:

gh pr list
Step 13: Merge PR

Agar review pass ho gaya:

gh pr merge

Ya:

gh pr merge --squash

Company me mostly squash use hota hai.

Step 14: Latest Main Pull Kar

Main branch pe aa:

git checkout main

Latest code:

git pull origin main

Ab login code main me aa gaya.

Important Commands
Current Branch
git branch
All Branches

Switch Branch

Create New Branch

Pull Latest Changes

Create PR

List PR

Merge PR
